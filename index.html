📦 ggplot2 · a gentle guide

ggplot2 is R’s beloved data‑visualisation package, built on the grammar of graphics. Instead of memorising dozens of chart types, you build plots layer by layer — data, aesthetics, geometries, scales, and facets.

✨ This page walks through the essential components with clear syntax and examples.

1. The core syntax

Every ggplot2 plot starts with the ggplot() function. You supply a data frame and map variables to visual properties (aesthetics). Then you add layers with +.

# basic template ggplot(data = your_data, aes(x = variable1, y = variable2, color = group)) + geom_point() + # layer: scatterplot labs(title = "My first plot") + theme_minimal()

2. Layers: the building blocks

📊

ggplot() + aes()

Set global data & mapping. aes() maps columns to x, y, colour, size, etc.

📈

geom_*()

Geometric objects: points, bars, lines, boxes… Each adds a visual layer.

🎨

scale_*()

Control axes, colours, sizes. e.g. scale_color_brewer().

🧩

facet_*()

Small multiples: split plot by a categorical variable.

📌 Most used geoms

  • geom_point() – scatter plots
  • geom_bar() / geom_col() – bar charts
  • geom_line() – line plots (time series)
  • geom_boxplot() – box‑and‑whisker
  • geom_histogram() – distribution
  • geom_smooth() – trend lines

3. Hands‑on example: scatter plot

🚗 mtcars: weight vs. miles per gallon geom_point

# load library library(ggplot2) # basic scatter: wt vs mpg, color by cylinders ggplot(data = mtcars, aes(x = wt, y = mpg, color = factor(cyl))) + geom_point(size = 3, alpha = 0.8) + labs(title = "Fuel efficiency vs weight", x = "Weight (1000 lbs)", y = "Miles per gallon", color = "Cylinders") + theme_minimal()

💡 aes(color = factor(cyl)) turns a numeric column into discrete categories. Try size = hp to map a continuous variable to point size.

4. Another layer: bar chart

📊 Count by category geom_bar

# using built-in diamonds data (first 500 rows for speed) ggplot(data = head(diamonds, 500), aes(x = cut, fill = cut)) + geom_bar(alpha = 0.8) + labs(title = "Diamond cut distribution", x = "Cut quality", y = "Count") + theme_classic() + theme(legend.position = "none") # remove legend if redundant

geom_bar() automatically counts rows. Use geom_col() when you already have a summary statistic.

5. Faceting: small multiples

Split your plot by a categorical variable with facet_wrap() or facet_grid().

# scatter plot split by transmission type (am) ggplot(mtcars, aes(x = wt, y = mpg, color = factor(cyl))) + geom_point(size = 2.5) + facet_wrap(~ am, labeller = label_both) + # 0 = automatic, 1 = manual labs(title = "MPG vs weight by transmission", color = "Cyl")

Use facet_grid(rows ~ cols) for a 2D grid of panels.

6. Scales & themes (the polish)

  • Scales: scale_color_manual(), scale_fill_gradient(), scale_x_log10() …
  • Themes: theme_minimal(), theme_bw(), theme_classic(), theme_light().
  • Labels: labs(title =, subtitle =, caption =, x =, y =).
# customizing color scale & using a clean theme ggplot(mtcars, aes(x = wt, y = mpg, color = hp)) + geom_point(size = 3) + scale_color_gradient(low = "#2c5f8a", high = "#e07a5f") + labs(title = "Horsepower vs weight", color = "HP") + theme_minimal(base_size = 14)

7. Quick workflow

  1. ggplot(data, aes(...)) – set the canvas.
  2. Add one or more geom_*() layers.
  3. Fine‑tune with scale_*(), labs(), facet_*().
  4. Pick a theme_*() and adjust fonts / colors.
  5. Save with ggsave("plot.png", width = 8, height = 5).

8. Pro tips

⭐ Mapping vs setting: inside aes() you map a variable (e.g. color = cyl); outside you set a constant (e.g. color = "blue").

⭐ Global vs local: ggplot(data, aes(...)) + geom_point() + geom_line() — both layers inherit the mapping. You can override inside a layer.

⭐ Pipe friendly: ggplot2 works beautifully with the native R pipe |> or %>%.
